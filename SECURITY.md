## Reporting a Vulnerability or Security Concern

If you discover a security vulnerability, exposed sensitive data, or an integrity issue within this repository:

1. **Do not open a public issue.**
2. Report the finding directly to **Marwan Elamami** via GitHub private vulnerability reporting or email: `marwanelamami13@gmail.com`.
3. Provide details regarding:
   - File path and commit hash.
   - Description of the security risk or exposed data.
   - Proposed remediation.
